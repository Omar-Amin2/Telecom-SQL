# Led a team of five members to design and develop a dynamic website that integrated seamlessly with a custom-built SQL database. The project began with designing an Enhanced Entity-Relationship Diagram (EERD) to model the database structure and relationships effectively. We then developed the database schema based on the EERD, ensuring scalability and efficiency. Utilizing ASP.NET 9, we built the website, focusing on a user-friendly interface and robust backend functionality. As the team leader, I coordinated tasks, guided team members through the development process, and ensured timely delivery of a high-quality product. This project demonstrated skills in database design, web development, and team leadership.
